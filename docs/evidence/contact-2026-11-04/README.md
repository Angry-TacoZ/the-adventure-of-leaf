# Leaf/rock refraction contact regression — November 4, 2026

These are crops of the same 1280 × 720 manual frame at 10.5 seconds, no wind, with planar reflection disabled to isolate refraction. Crop: x=550, y=490, width=550, height=120. Chrome used native WebGPU; adapter reported NVIDIA Lovelace, non-fallback. Images are compositor captures, not edited illustrations.

[Before](before.png): the old 3–10 cm continuity band produced detached gold components of 10, 4, 3 and 3 pixels above the main leaf region (38,434 pixels). This screenshot was generated by intercepting the water module and restoring only the old threshold. The new automated test fails against that counterfactual.

[After](after.png): a 2–10 mm band rejects the same discontinuity and uses undistorted scene color. The main leaf region remains 38,434 pixels, with no detached gold components. Forced SwiftShader WebGL2 also passes, with one 38,478-pixel region. No reflection, submersion exclusion or artificial physics lift was introduced.

The test is deliberately a bounded regression for this deterministic contact/camera, not a claim that all screen-space disocclusion artifacts are solved. Depth changes now suppress refraction earlier; offscreen information remains unavailable. Full submersion/silhouette and foreground suites must pass alongside this check.
