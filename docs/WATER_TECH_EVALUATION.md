# Water technology evaluation (2026-10-29)
Choose a small independently written WebGL2-compatible Three.js water surface with analytic waves and a shared CPU height/current sampler for the river prototype. This avoids coupling leaf movement to a separate GPU simulation and works on the standard Three.js WebGL renderer; it is an approximation, not full fluid dynamics. Planar reflection/refraction captures are now implemented as described below; localized wakes remain future work.

- [Evan Wallace's WebGL Water](https://github.com/evanw/webgl-water) is a bounded pool heightfield with raytraced reflection/refraction, caustics and floating-point texture requirements. The repository has no identified license file via GitHub; do not copy it without verified rights. It does not provide an out-of-box downstream river current.
- [Three.js adaptation](https://github.com/jeantimex/threejs-water) is MIT licensed with original and modified copyright notices. Its current package uses Three.js 0.184 and Vite, but its pool simulation and GPU readback/integration cost require additional work for current-driven leaf motion. No code or assets are copied.
- [SeedOcean](https://github.com/reed-soul/SeedOcean) is MIT licensed, WebGPU-first with WebGL2 fallback, FFT waves, foam and buoyancy. Designed for ocean water, it is substantially larger than needed for a narrow current-driven river; combining it with a second engine is unjustified.
- [After Rain](https://github.com/HiliMor/after-rain) is all rights reserved; no copying permitted. It is a visual benchmark only. [Ripple](https://ripple.carsonye.com/) is a movement benchmark; its source/license has not been established, so do not reuse assets or code.

WebGPU may provide headroom later but support, packaging and fallback testing add risk; WebGL2 is the initial target. This model does not yet implement physically correct refraction, dynamic obstacle wakes or raytraced reflection; performance and device compatibility require measurement. Desktop shells must be tested with their actual graphics backends.

## Reflection/refraction correction

Use the existing Three.js MIT-licensed Reflector and Refractor helpers for two 512-square scene captures (reduced with quality), combined in independently authored src/water.ts. Fresnel blending increases reflection toward grazing angles. Snell's law (air/water index 1/1.333) bends the view ray toward the shallow planar bed. The dynamic geometry and interpolated normals come from the same surface sampled by leaf physics. Capture planes are positioned at the mean water height, an approximation for waves. This is rasterized planar optics, not the reference demo's raytraced pool renderer. No Evan Wallace demo source, images or tile texture is copied.

Evan Wallace's [caustics article](https://medium.com/@evanwallace/rendering-realtime-caustics-in-webgl-2a99a29a0b2c) describes refracting light-ray mesh vertices onto receiving geometry, then estimating concentration from the original/projected area ratio using fragment derivatives. It can be investigated as a later pass using our shared wave normals; it requires an additional receiver-lighting step and is not supplied merely by reflection/refraction. Caustics are not implemented in this pass. The prototype's riverbed texture is generated in project code to make transmitted distortion observable.
